## Moduły CRM

### Dashboard
- Strona główna po zalogowaniu
- Widgety ze statystykami, aktywni użytkownicy, ostatnie aktywności
- Changelog systemu

### Kalkulator
- Menu boczne → "Kalkulator" lub /calculator/
- Wycenianie dowolnych wymiarów — gatunek, technologia, wykończenie
- Po wycenie można zapisać ofertę i wysłać klientowi link

### Wyceny
- Lista ofert dla klientów
- Format numeru: NN/MM/RR/W (np. 203/10/25/W)
- Statusy: Szkic, Wysłana, Zaakceptowana, Odrzucona

### Klienci
- Baza kontrahentów
- Dane kontaktowe, adresy dostawy, NIP
- Powiązane wyceny i zamówienia

### Produkcja
- 6 stanowisk: wycinanie → składanie → sklejanie → formatowanie → wykańczanie → pakowanie
- Zarządzanie zleceniami produkcyjnymi

### Raporty
- Analizy sprzedaży i statystyki
