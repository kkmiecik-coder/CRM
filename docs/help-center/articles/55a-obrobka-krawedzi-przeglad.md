# Obróbka krawędzi — przegląd

Krawędzie produktów WoodPower możemy wykończyć na kilka sposobów. Dostępne rodzaje obróbki krawędzi to:

- Krawędź ostra (prosta) — standardowa, prosta krawędź bez dodatkowej obróbki.
- Krawędź fazowana — ścięta pod kątem 45° lub 60° (skos).
- Krawędź zaokrąglona — zaokrąglona z wybranym promieniem R.

Obróbka krawędzi nie musi być jednakowa dla całego produktu — można wskazać, których krawędzi ma dotyczyć dany rodzaj obróbki. Rodzaj obróbki krawędzi ustalamy i wyceniamy indywidualnie.
